# Link Puzzle Editor (基于约束求解的网格谜题编辑器)

这是一个基于 Python 和 Pygame 开发的模块化网格谜题编辑器。它不仅支持绘制和编辑多种类型的逻辑谜题，还集成了基于 `cspuz` 的强大约束求解器，能够自动求解盘面或进行逻辑推演（找出当前局面下的可推部分）。

## 主要功能

*   **多模式编辑**：支持放置各种谜题线索（数字、端点、珍珠、墙壁等）。
*   **智能绘图**：
    *   支持鼠标拖拽连续画线/画叉。
    *   支持格内元素（如数织）和格点元素（如数回）的混合编辑。
*   **约束求解 (Solve)**：计算谜题的一个可行解，并在盘面上显示。
*   **逻辑推演 (Deduct)**：模拟人类逻辑，计算当前盘面下所有**确定**的线段和叉（Backbone Computing），辅助解题而不直接给出全部答案。
*   **异步计算**：求解过程在独立进程中运行，带有进度弹窗和中止按钮，防止界面卡死。
*   **文件存取**：支持将盘面保存为 JSON 格式或读取已有进度。

## 支持的谜题元素与规则

目前的求解器 (`solver.py`) 支持以下元素的混合约束：

-  **连线 (Numberlink)**：相同数字的端点必须相连，且路径不交叉。
-  **Slitherlink**：格点上的数字表示周围四条边中有几条被连线。
-  **Masyu**：
    *   **白圆**：必须直行通过，且通过前或通过后必须转弯。
    *   **黑圆**：必须转弯（90度），且转弯后的两段直线必须延伸至少 2 格。
-  **简单回路 (Simple Loop)**：必须有线条经过此格。
-  **墙壁 (Wall)**：线条不能经过此格。
-  **全局约束**：所有线条必须构成无环路径。

## 安装与环境配置

本项目依赖 Python 3.x。

### 1. 安装基础依赖
请通过 pip 安装 Pygame：

```bash
pip install pygame
```

### 2. 安装 cspuz (关键)
本项目核心求解逻辑依赖于 **cspuz** 库。

**项目地址**: [https://github.com/semiexp/cspuz](https://github.com/semiexp/cspuz)

### 3. 运行项目
确保所有文件在同一目录下，运行：

```bash
python main.py
```

## 操作说明

### 鼠标操作
*   **左键点击**：选择工具栏物品 / 在网格上放置物品。
*   **左键拖拽**：
    *   若选中普通物品：批量放置。
    *   若选中“线/叉”工具：连续画线。
*   **右键点击/拖拽**：删除物品 / 进行反向操作（如橡皮擦、画叉）。
*   **中键拖拽**：平移视图。

### 键盘快捷键
*   **数字键 (0-9)**：修改当前鼠标指向物品的数值（如端点数字、Slitherlink 数字）。
*   **空格键 (Space)**：将当前物品数值重置为 0。
*   **R 键**：重置视图位置到初始点。

### 界面按钮
*   **SOLVE (求解)**：计算并显示一个可行解。
*   **DEDUCT (推演)**：计算所有逻辑上必然存在的线或叉。
*   **WIPE (清空)**：仅清除盘面上的连线和标记，保留题目线索。
*   **CLEAR (重置)**：清空整个盘面（包括线索）。
*   **SAVE/LOAD**：保存或读取 `.json` 格式的关卡文件。

## 项目结构

*   `main.py`: 程序入口。
*   `editor.py`: 编辑器主逻辑、输入处理、多进程管理。
*   `map_objects.py`: 定义所有盘面物件（外观、属性）。
*   `solver.py`: **核心算法**。构建 `cspuz` 模型，定义数学约束。
*   `renderer.py`: 负责屏幕渲染绘制。
*   `actions.py`: 处理物品放置、删除等具体逻辑操作。
*   `worker.py`: 独立进程的求解器包装器。
*   `io_handler.py`: 文件读写处理。
*   `ui.py`: 简单的 UI 按钮组件。
*   `config.py`: 全局配置（颜色、尺寸等）。
